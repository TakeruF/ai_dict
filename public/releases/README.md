# AI Dict - Android Beta Release

## ダウンロードとインストール

### 1. APKファイルのダウンロード
- Webサイト左側のメニューから「Android版 (Beta)」ボタンをクリック
- `ai-dict.apk` ファイルがダウンロードされます

### 2. インストール手順

#### 提供元不明のアプリを許可:
1. **設定** → **セキュリティ** → **提供元不明のアプリ**を有効化
   - または **設定** → **アプリ** → **特別なアクセス** → **不明なアプリのインストール**
2. ブラウザアプリ（Chrome等）に対してインストールを許可

#### APKをインストール:
1. ダウンロード完了後、通知からタップ
   - またはファイルマネージャーからダウンロードフォルダを開く
2. `ai-dict.apk` をタップ
3. 「インストール」をタップ

### 3. 初回起動
- アプリアイコン「AI Dict」をタップして起動
- 初回は読み込みに少し時間がかかる場合があります
- Googleアカウントでログインするか、招待コードを入力してご利用ください

### 4. 注意事項
- **Beta版**: 開発中のバージョンです
- **セキュリティ**: Google Play外からのインストールです、自己責任でご利用ください  
- **更新**: 新バージョンは手動でダウンロード・インストールが必要です

### 5. 問題が発生した場合
- アプリを削除し、最新版を再ダウンロード
- ブラウザ版（https://aidict.me）をご利用ください
